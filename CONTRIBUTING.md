# Contribuer à HomePilot

Merci de l'intérêt pour ce projet.

## Règles de contribution

- Respectez le style de code existant.
- Vérifiez les tests avant de proposer une modification.
- Gardez les changements ciblés et lisibles.
- Ajoutez des tests pour les nouvelles fonctionnalités quand c'est possible.

## Vérifications locales

```bash
flutter analyze
flutter test
```

## Proposition de modification

1. Créez une branche dédiée.
2. Implémentez votre changement.
3. Vérifiez la qualité du code.
4. Ouvrez une pull request claire et décrite la finalité du changement.
